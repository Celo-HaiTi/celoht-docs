

# CeloHT Metrics Framework

**Version:** 1.0

**Status:** Active

**Last Updated:** August 2026

---

# Purpose

The CeloHT Metrics Framework defines how the project measures impact, transparency, sustainability, adoption, and ecosystem growth across all CeloHT initiatives.

All metrics must be measurable, verifiable, transparent, privacy-respecting, and reproducible.

Metrics are published through the CeloHT dApp, website, and public transparency reports.

---

# Core Principles

Every metric published by CeloHT must follow these principles:

- Accuracy
- Transparency
- Accountability
- Privacy
- Consistency
- Auditability

No metric may be intentionally manipulated or published without supporting evidence.

# Verification Policy

All published metrics should be supported by one or more of the following:

- Blockchain Records
- Smart Contract Events
- Backend Logs
- Financial Records
- Attendance Records
- GitHub Activity
- Field Verification
- Community Reports

Metrics found to contain errors must be corrected publicly and documented through the project's changelog.
